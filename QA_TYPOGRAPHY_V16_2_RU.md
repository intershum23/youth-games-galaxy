# v16.2 — единая типографика на базе текущей v16.1

**Montserrat — основной UI. Unbounded — названия игр, крупные заголовки, ключевые цифры и главные CTA.**

В `typography.css` заданы единые `--font-ui` и `--font-accent`. Старые прямые объявления Arial/Helvetica/system-ui заменены этими токенами в главной странице, shell и исходном CSS всех 16 игр. Технические fallback находятся после Montserrat/Unbounded в определении токенов. Shorthand `font` также исправлен: он больше не сбрасывает шрифт к system-ui. Все 16 `.galaxy-title` используют Unbounded.

Локально включены WOFF2 Montserrat и Unbounded, веса 400/500/600/700/800/900, кириллица, расширенная кириллица, латиница и дополнительные subsets. Внешний font CDN не нужен. Источник: @fontsource/montserrat 5.3.0 и версия @fontsource/unbounded из `assets/fonts/FONT_SOURCES.json`. OFL-лицензии включены рядом со шрифтами.

Проверено:

- главная страница и 16 игр подключают локальную шрифтовую систему;
- CSS всех 17 основных страниц и shell не содержит постороннего основного font-family;
- 60 файлов WOFF2 декодированы без ошибок;
- обе семьи во всех шести весах покрывают русские названия игр, Ё/ё, цифры и `by Alexey Kuznetsov`;
- 476 ссылок на ресурсы — 0 отсутствующих; 25 JS syntax checks — 0 ошибок;
- встроенные игровые scripts всех 16 игр и 5 основных JS-файлов побайтово совпадают с v16.1; изображения эталонных героев сохранены.

Native runner теперь ожидает `document.fonts.ready`, проверяет действительно загруженные семьи и Unbounded в computed style игрового заголовка.

**Реальный браузерный рендер этой редакции не проверен.** Прежний инфраструктурный blocker сохраняется. Наследованные DOM-результаты — история v16.1, они не выдаются за повторный прогон v16.2. Старые 48 мобильных строк остаются BLOCKED; переносы, размеры текста, загрузка шрифтов и отсутствие новых наложений на 360×800, 390×844, 430×932 ещё требуют проверки в браузере. Порядок запуска и preview QA — `qa/README_RU.md`.
