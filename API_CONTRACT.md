# API для глобальных рекордов (опционально)

Текущая сборка работает без сервера и хранит рекорды локально. Для общего онлайн-рейтинга можно подключить API.

Рекомендуемые endpoints:

- `POST /api/records` — сохранить результат: `{gameId, playerName, score, meta, createdAt}`
- `GET /api/records?gameId=<id>&limit=20` — топ по игре
- `GET /api/players/<name>` — профиль игрока
- `GET /api/leaderboard` — общий рейтинг, если будет согласована формула начисления очков между разными играми

Важно: у игр разные метрики. Для Пятнашек лучше меньше ходов/времени, в большинстве других игр лучше больше очков. Поэтому общий межигровой рейтинг нужно считать по отдельно согласованной формуле, а не просто складывать исходные значения.
