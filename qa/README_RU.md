# Повтор QA v16

Из каталога `qa`: `npm install`, `npx playwright install chromium`.
Затем `npm run dom`, `npm run variants`, `npm run protocol`, `npm run browser`.
Тесты используют порт 8765; запускать последовательно.

`browser-qa.cjs` — только настоящий Playwright Chromium: 16 игр × 3 портретных размера,
скриншоты заставок/меню/modal/поля, игровые действия, landscape-поворот, геометрия,
навигация, ошибки console/page/network, сохранность localStorage после reload.
Для своего бинарника используйте `QA_BROWSER_PATH`; дополнительные args — JSON-массив
в `QA_BROWSER_ARGS`. При launch failure матрица получает BLOCKED, а не PASS.

В этой среде браузер не запустился. DOM-тесты не вычисляют геометрию и не проверяют touch.
Даже после автоматического PASS необходимо вручную просмотреть реальные скриншоты,
пройти дополнительные режимы и конечные состояния. При несовпадении ручного и
автоматического результата отчёт должен отражать дефект.

Файлы `QA_V15_RU.md` и `qa/results/v13-observer-reproduction.json` — историческая информация.
Актуальный отчёт — `QA_V16_RU.md`.

## Доступный preview

Для проверки уже размещённой текущей v16: `QA_BASE_URL=https://your-preview.example/ npm run browser`. URL — каталог с `index.html`; локальный сервер тогда не запускается. Нужен браузер в исполняющем тесты окружении.

Для ручной проверки откройте `qa/mobile-lab.html` на том же preview. Вложенное окно платформы имеет точные размеры 360×800, 390×844 или 430×932. Кнопка «Повернуть» меняет ширину и высоту без сброса партии. Внешняя прокрутка позволяет осмотреть окно целиком. Не путать такую проверку с физическим Android: нативные touch, browser chrome, DPR и экранная клавиатура требуют отдельных проверок.
