# Игровая галактика v16.16.0 — Радиомаяк и реальный QA

Дата: 5 октября 2026. Исходник — существующий GitHub main 1467352fe0f6caaf8d86c7a8c0153e0fd3c88f74, v16.15.0. Scratch предыдущей сессии был очищен обслуживанием среды; работа восстановлена из репозитория, без пересоздания платформы. Новая сборка содержит 19 действующих игр.

## Реализация

Добавлен настоящий Радиомаяк (gameId radio-beacon): поиск частоты по видимой силе сигнала, явная фиксация, три сообщения, непрерывный запас связи, дрейф, предупреждаемые помехи, победа/поражение, звук, pause/replay/menu/fullscreen, отдельные рекорды A/B/TURBO. Все числовые правила описаны в games/radio-beacon/SPEC_radio-beacon.md. Здесь нет сортировки, перехвата, фиктивного соперника или нарисованной игровой панели.

Ресурсы: новая обычная и активная иконки Корги с приёмником, 9:16-заставка обоих героев, прозрачное PNG-название из настоящего Unbounded 800, оптимизированные WebP, manifest SHA-256 и происхождение. AI-надпись на заставке лишь стилистический ориентир; отдельный PNG-title использует реальные шрифтовые глифы. UI Montserrat, акценты Unbounded. Космо-Кот белый, круглые оранжевые очки сохранены. Прозрачные контейнеры и три экрана общей оболочки. Игровые антенна, индикаторы и управление реализованы SVG/HTML/CSS.

В каталоге 19 игр; поиск/категория Ретро-орбита/активная иконка/центрированное название работают через существующую платформу. Общий адаптер retro-score теперь отображает messages, а не ноль вместо числа сообщений. Архитектура v15/v16 и загрузочный lifecycle сохранены. Старые compatibility-слои не возвращены. Старые 18 движков и их ресурсы не менялись.

## Среда

Playwright и настоящий Chromium 153, headless. Телефон: 360×800, 390×844, 430×932, touch emulation с настоящими touchscreen.tap. ПК: 1280×800, 1920×1080. Native кнопки, keyboard и range. Изменение viewport проверяет безопасный поворот, но не физическое Android-устройство. QA-adapter только readonly snapshot; не показывает искомую частоту, не позволяет менять игру.

Глубокий тест ищет частоту реальными кнопками только по проценту силы сигнала. Не читает hidden target и не подменяет progress, время, энергию, очки или победу. Каждый успех требует три сообщения, phase=result, остановленный RAF, одну запись с won=true и messages=3. После этого проверяются «Ещё раз», меню, вкладка рекордов, общий каталог, обновлённый best и reload.

Граничные сценарии: три естественных поражения на нулевом запасе; прямое открытие на пяти размерах; клавиатура/Shift/границы 0 и 100/range/touch slider; pause и блокировка действий; поворот; Web Audio running/suspend/отсутствие голосов после mute; native кнопка fullscreen вход/выход; возврат; TURBO предупреждение/всплеск/расход при ошибочной фиксации/снятие; отсутствующая заставка и retry; повреждённый/запрещённый localStorage с естественной победой; синтетическая visibilitychange-пауза с явным продолжением.

В общей регрессии старых игр PASS означает хотя бы реальное базовое действие, а не полное прохождение всех вариантов. Маджонг — снятие пары; Мемори — завершение совпадающих пар; Судоку — заметки/удаление/цифра/проверка/подсказка; Пасьянс — stock; Звёздный бой — расстановка и выстрел; настольные — реальный ход; Капсулы — перехват; Почта — доставка; Радиомаяк — изменение частоты. Подробная проверка foundation Пасьянса из v16.15 сохранена как историческое доказательство, заново в этом этапе не проводилась: код Пасьянса не изменён.

## Обнаруженное и исправленное при QA

Два desktop сценария первого глубокого прогона остановились по тайм-ауту: победная передача успела закончиться между чтением состояния и очередным кликом теста; кнопки уже отключены и открыта настоящая победная modal. На скриншотах — корректная победа 3/3. Тест теперь учитывает асинхронное завершение, продолжает проверку только при настоящем result/messages=3, иначе ошибка остаётся. Код игры для обхода теста не менялся. Финальная матрица получена повторным полным прогоном всех 15 сценариев.

Кнопки шага приведены к touch-height 44px. Лишние мелкие стрелки-подсказки убраны из кнопок −/+; клавиатура остаётся рабочей. Окончательный layout проверен после правки. Никаких force-click через modal или JS-подмен игровых результатов нет.

## Ограничения / NOT_RUN

- Физический Samsung/Android, One UI, iOS/Safari, Firefox, разные GPU и длительный playtest человеком.
- Слышимый вывод звука: проверен аудиограф, но headless аудио не прослушивалось.
- Реальный переход вкладки в background: synthetic visibility fixture явно отделён.
- Native Escape выхода fullscreen; проверена настоящая кнопка «Экран».
- Все уровни и все терминальные состояния прежних 18 игр; baseline не заменяет полного QA каждой механики.
- Долговечное сохранение при запрещённом браузером storage; сама игра продолжает работать.
- Остальные 9 кандидатов shortlist ещё не реализованы; следующая игра — Реактор: три режима.

## Воспроизведение

node qa/radio-beacon-qa.cjs — глубокая матрица, QA_WIDTHS/QA_MODES позволяют выбрать поднабор. node qa/radio-beacon-edge-qa.cjs — граничные сценарии. QA_BROWSER_PATH и QA_BROWSER_ARGS — общий baseline; QA_OUT_DIR задаёт output: node qa/browser-qa.cjs. QA_RECORDS_OUT задаёт путь unit JSON: node qa/retro-records-unit.cjs. node tools/build-catalog.cjs валидирует и выполняет сгенерированный JS. qa/radio-beacon-published-qa.cjs — live-smoke; QA_USE_PROXY=1 для этого окружения.

Production остаётся статическим сайтом без npm runtime. Исходные PNG и итоговые WebP находятся в проекте; скриншоты QA — настоящие браузерные снимки, без дорисовки и замены preview-артом. ZIP проверяется CRC и SHA-256 внутренних файлов.
