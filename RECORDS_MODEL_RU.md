# Модель рекордов без регистрации

## Сейчас в v4
- Платформа не создаёт аккаунт, профиль или аватар.
- Раздел называется «Мои рекорды».
- Результаты читаются из localStorage игр и показываются как личные достижения этого устройства.
- Если результатов нет, вместо 16 пустых таблиц показывается один понятный empty-state.
- Имена игроков в общем интерфейсе платформы не используются.

## Когда понадобится общий рейтинг между устройствами
Регистрация не обязательна. Можно использовать анонимную схему:

1. При первом открытии браузер создаёт случайный `device_id` (UUID) и хранит его локально.
2. После партии игра отправляет на API: `device_id`, `game_id`, результат, режим, сложность, дополнительные метрики и время.
3. Для публичной таблицы можно попросить ввести короткий ник только при попадании в рекорд. Это не аккаунт и не регистрация.
4. Сервер хранит результаты и отдаёт TOP по каждой игре.
5. Пароли, email, аватары и обязательные профили не нужны.

Так можно получить общий рейтинг для всех посетителей, сохранив вход в игры максимально простым.
