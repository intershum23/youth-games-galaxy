# Промпт добавления игры в «Игровую галактику»

Создай игру «[НАЗВАНИЕ]», id [ID], правила [ПРАВИЛА], режимы [РЕЖИМЫ]. Работай в текущей сборке, сохрани архитектуру загрузки, lifecycle, records и modal. Не создавай новую платформу и не добавляй compatibility-слои.

UI: Montserrat; названия, ключевые цифры и CTA: Unbounded. Используй общие typography.css, game-shell.css, game-shell.js, game-lifecycle.js и существующую интеграцию результатов. Космический фон, прозрачные панели трёх плотностей: выбор 0.34, активный статус 0.46, dialog 0.66. Доска, карты и символы должны оставаться контрастными. Поле важнее декоративной обвязки. Минимальный целевой touch target 44px. Проверяй 360×800, 390×844, 430×932 и безопасный landscape.

Герои неизменны: взрослый рыже-белый Капитан Корги и белый Космо-Кот с круглыми оранжевыми очками. Используй оригинальные assets/corgi.png и assets/cat.png на выборе героя. Изображения целиком видны, имеют безопасные поля и object-fit:contain. Не рисуй кнопки в иллюстрациях.

Нужные изображения: icon.webp (основная поза), icon-active.webp (вторая поза того же героя и предмета, минимальное движение, та же камера и масштаб), splash.webp (без нарисованных UI), title.svg/PNG (прозрачный фон; точная надпись из Unbounded, единая космическая стилистика). Сохраняй альфа-канал. Иконка и вторая поза не должны обрезаться. При reduced-motion показывай основную позу.

Загрузка сообщает ready только после готовности DOM, ресурсов и обработчиков. Выход прекращает таймеры и звук. Изолируй состояние игры, не используй общий window.onload. Modal: одна карточка, вертикальная структура, role=dialog, aria-modal, trap focus, восстановление фокуса, закрытие и безопасная прокрутка. Не добавляй произвольные глобальные CSS-селекторы.

Результат: сохранение через текущий контракт records, повтор партии, меню и Все игры. Проверяй отсутствие дублирования результатов и сохранение после reload. Если игра поддерживает возобновление, задай отдельный versioned save-state adapter; иначе не называй повторное открытие «продолжением партии».

Подключение: добавь запись games-manifest.json с id/title/full/desc/cat/color/entry/keys/version/assets; запусти node tools/build-catalog.cjs. catalog.generated.js — производный файл, вручную не редактировать. Код должен использовать пути реестра. Для нетипичной структуры рекордов добавь явный formatter в asRows; наличие keys само по себе не подключает новый формат результатов.

QA: реальный Chromium, все три размера, заставка → выбор героя/режима → реальное игровое действие с проверкой изменения состояния → новая партия → меню → каталог → reload. Проверь portrait/landscape, ресурсы, console/page errors, наложения, размеры поля, читаемость title, localStorage. Отдельно проигрыш/победа/ничья, если применимо. Не считать открытие экрана прохождением. Отметь FAIL/BLOCKED/NOT_RUN честно. В архив включи отчёт, исходники и SHA-256.

Текущий визуальный стандарт v16.9: выбранный герой отмечается только общей галочкой (без локальных ::before-бейджей ВЫБРАН). title.png с альфа-каналом обязателен на всех экранах и в каталоге; SVG-контуры Unbounded сохраняются как исходник. Карточка каталога наследует центральный масштаб 1.00–1.35 и увеличение второй позы в 1.3 раза относительно первой. При нажатии превью длится 150 ms, первое короткое касание запускает игру через общий pointerup; повторные нажатия дают один запуск; свайп должен прокручивать страницу без запуска. Не копируй эти handlers в отдельную игру.

Названия: сгенерированный прозрачный объёмный PNG в едином стиле (peach/pink, violet bevels, cyan orbit accents), референс — установленный assets/titles/chess.png. Текст короткий и точный; буквы по форме Unbounded Bold. Не обещать точное совпадение гарнитуры у AI-рисунка без проверки. Использовать одну картинку в каталоге, выборе героя и игре; не изменять готовую заставку. Проверить задержанную загрузку заставки: модальное окно игры показывать только после декодирования постера, не выводить промежуточный фон.
